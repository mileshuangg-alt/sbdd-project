# Development Policy

## Scientific core — write and understand ourselves

Code that determines scientific meaning is authored/reviewed directly by the project:

- scientific transformations
- interaction interpretation
- gate and verdict logic
- claim propagation
- coordinate and atom mapping
- selection and routing logic

These functions must be understood before they are accepted into the evaluation pipeline.

## OpenCode — implementation aid

OpenCode may be used for mechanical implementation work after scientific behavior is understood and frozen:

- CLI wrappers
- batch runners and orchestration
- hashing and checksums
- manifests and provenance plumbing
- test scaffolding
- repetitive execution
- mechanical refactoring

OpenCode is an implementation aid, not a substitute for understanding or authoring the scientific methodology.
